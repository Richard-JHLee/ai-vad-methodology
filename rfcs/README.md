# RFCs

This directory holds **Requests for Comments** that evolve VAD.

| Number | Title | Status |
| ------ | ----- | ------ |
| [0001](./0001-vad-core.md) | VAD Core | Draft |

## How to propose an RFC

1. Open an issue for discussion when possible.
2. Copy the structure of `0001-vad-core.md`.
3. Use the next available number: `NNNN-short-title.md`.
4. Add a row to the table above with status `Draft`.
5. Submit a pull request.

## Status values

* **Draft** — under discussion
* **Accepted** — adopted into the methodology guidance
* **Superseded** — replaced by a later RFC
* **Rejected** — not adopted; keep for history
